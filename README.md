# SPECTR
**Цель:** создание OSINT-бота на Python, который по переданному username собирает доступную публичную информацию из 
интернета и Telegram

Основные функции
1. Telegram Serch
    - Поиск публичных сообщений пользователя
    - Поиск упоминаний пользователя другими людьми
    - Поиск по публичным Telegramm-чатам и каналам

2. Internet Serch
    - Поиск информации через Google? Bing и поисковые API
    - Поиск публичных страниц, публикаций и упоминаний

3. Social Media Search
    - Поиск возможных аккаунтов человекав разных соцсетях
    - Поиск по username
    - Составление профилей по публичным признакам: биография, ссылки, фотографии и другие совпадения

4. Profile Analysis
    - Сбор найденной публичной информации
    - ССылки на источники
    - Даты публикаций
    - Найденные совпадения и степень уверенности 


Технологический стек:
- Python - основной язык
- Telebot - Telegram-бот
- Telethon - работа с Telegram API
- Paywright - автоматизация браузера
- BeautifulSoup - обработка веб-страниц
- aiohttp - HTTP-запросы
- PostgreSQL - база данных
